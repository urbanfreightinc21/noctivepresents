# Noctive Website Replacement Files

These files replace the default Next.js homepage already created in your GitHub Codespace.

## Install in your Codespace

1. Upload `noctive-site-files.zip` into the root of the repository.
2. In the Codespaces terminal, run:

```bash
unzip -o noctive-site-files.zip
npm run dev
```

3. Open the forwarded port when GitHub offers it.
4. When the site looks correct, commit it:

```bash
git add .
git commit -m "Build Noctive website"
git push
```

## Included

- `app/page.tsx`
- `app/globals.css`
- `app/layout.tsx`
- `public/noctive-logo.png`
- `public/noctive-poster.png`
- `public/noctive-hero.mp4`

The site contains no Riot Ten or Night Pulze material.
Instagram is set to `@noctivepresents`.
